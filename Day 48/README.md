## ⚠️ Things to Remember
- selenium can work with different browsers, the browser is declared when created an object. each browser uses different driver
- to keep chrome open add chrome options and pass it to the webdriver
- IF there is no identifiable class name or id usee CSS_Selector (div class and tag)
- Xpath can be used when something is really hard to find. this is found via developers tools by right clicking the element and copying the path
- get hold of the element and use .click method to click links
- selenium has  by link  to find links by text
- .send_keys to  type
- use the keys class for things other than writen characters like enter
