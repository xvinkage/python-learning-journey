## What I Learned
- Python automatically converts division (`/`) results to a float.
- `**` is the exponent (power) operator.
- `round()` rounds numbers to the nearest whole number or to a specified number of decimal places.
- f-strings allow variables and expressions to be embedded directly inside strings, making code easier to read.
- Data often needs to be converted using `int()`, `float()`, or `str()` before it can be used correctly.

## Things to Remember
- Python follows the order of operations (PEMDAS).
- `int()` truncates (removes) the decimal portion—it does **not** round.
- Assignment operators can simplify code:
  - `+=`
  - `-=`
  - `*=`
  - `/=`
- You cannot concatenate a string and an integer without converting one of them.

## Key Takeaways
- Always know what data type you're working with.
- Most bugs involving calculations come from using the wrong data type.
- Converting data types is a common part of programming.
