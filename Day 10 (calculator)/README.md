## 💡 What I Learned
- `return` = the output/result of a function
- `return` passes information back but does not print it
- you can use the returned output of one function as the input for another
- `return` ends the function
- a docstring is a way to document what a function does using `""" """` directly after declaring the function
- you can store functions in variables, just don't put `()` when storing the function
- functions can be used as values in dictionaries
- a function can perform an action and return the result for another part of the program to use

---

## ⚠️ Things to Remember
- functions reduce the amount of code we write by allowing us to reuse code
- arguments get passed into parameters
- `return` gives information back to the part of the program that called the function
- `print()` displays information, while `return` passes information back
- CHECK EXCEPTIONS FIRST!!!!!
- recursion is when a function calls itself
- when storing a function in a variable or dictionary, use the function name without `()`

---

## 🚀 Key Takeaways
- The biggest lesson from today was understanding the difference between `print()` and `return`
- `return` allows functions to produce information that can be stored and used elsewhere
- Functions don't just perform actions; they can calculate something and give the result back to the program
- I learned that programming is not just about knowing Python syntax, but also about thinking through how information flows through the program
