## 💡 What I Learned

- Practice reading documentation and implementing what I find.
- `from file import Class` can simplify imports when I only need specific classes or functions.
- Using `*` to import everything can make code harder to understand and should generally be avoided.
- `import turtle as t` is an example of aliasing a module.
- Python tuples use parentheses, such as `(1, 3, 8)`.
- Tuples are immutable, meaning their values cannot be changed after creation.
- Tuples can be converted into lists when I need a mutable version.
- Turtle can accept RGB tuples when color mode is set appropriately.
- I can use PyPI and documentation to learn how packages and modules work.

---

## ⚠️ Things to Remember

- PyPI is a repository for Python packages.
- Packages that aren't included with Python may need to be installed with `pip`.
- Make sure packages are installed in the correct virtual environment.
- A `(venv)` virtual environment provides an isolated environment for a project.
- `pip` is used to install Python packages.
- Avoid `from module import *` because it can make it unclear where names came from.
- Tuples are immutable.
- Lists are mutable.
- When using an unfamiliar module, check its documentation instead of guessing how its methods work.

---

## 🚀 Key Takeaways

- The biggest lesson today was learning to **use documentation to figure out how Python modules and their methods work** instead of relying entirely on memorization.
- I also learned that Python's data structures and imports can affect how easy my code is to understand and maintain.
- This will help me become more independent when working with new Python libraries and eventually building projects that use external packages.
