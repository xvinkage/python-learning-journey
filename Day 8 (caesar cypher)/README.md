## 💡 What I Learned

- A function with a named variable needs to have a value for that variable when the function is called
- Parameter and argument:
  - Parameter is the name of the data
  - Argument is the value of the data
- Positional arguments are assigned based on their order
- Keyword arguments allow you to explicitly assign values to parameters
- Functions can accept multiple parameters
- The `%` operator can be used to wrap values around a fixed range
- How to use a `while` loop to allow a program to repeat
- How to use `if/else` statements to control program flow
- How to handle characters that aren't included in a list

---

## ⚠️ Things to Remember

- Functions are blocks of code with a name. They allow us to package code into a named block to be used repeatedly
- Common bugs
- You can pass multiple parameters with a function
- Parameters and arguments are taken in order unless defined (positional arguments) unless you use keyword arguments
- `%` gives you the remainder and can be used to make values wrap around
- Pay attention to indentation because it controls which code belongs to an `if`, `else`, loop, or function

- Biggest lesson from today

- Concept that finally "clicked"
