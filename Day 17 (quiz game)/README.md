## 💡 What I Learned

- Use `pass` as a placeholder for an empty class or function when I haven't written the code yet
- Classes are named using PascalCase
- A class acts as a blueprint for creating objects
- `__init__()` is a special method that initializes an object's attributes when the object is created
- Code inside `__init__()` runs whenever a new object is created
- Attributes are variables/data that belong to an object
- I can convert data from dictionaries into objects and store those objects in a list

---

## ⚠️ Things to Remember

- `self` refers to the object that was created
- `__init__()` initializes the object's attributes
- Attributes = what the object has
- Methods = what the object does
- A class = blueprint for creating objects
