## 💡 What I Learned

- HTML boilerplate is the basic structure of an HTML file. It is what you typically start with when creating a new HTML page.
- The `<ol>` element creates an ordered list, while `<ul>` creates an unordered list.
- Ordered lists display numbered items, while unordered lists display bullet points.
- Lists can be nested inside other lists to create sub-lists.
- The `<a>` anchor element with an `href` attribute creates a hyperlink.
- HTML elements can have attributes that provide additional information or functionality.
- Some attributes are global attributes and can be used on many different HTML elements, such as `draggable`.
- Some attributes are specific to particular HTML elements.
- The `src` attribute tells an `<img>` element where to find the image.
- The `<img>` element is a void element and does not have a closing tag.
- The `alt` attribute provides alternative text for an image. It is important for accessibility and can also be displayed when an image cannot be loaded.

---

## ⚠️ Things to Remember

- HTML elements can be nested inside other elements.
- Use indentation to make nested HTML easier to read and understand.
- Global attributes can be used on many different HTML elements.
- Element-specific attributes are only valid or meaningful for certain elements.
- `<img>` is a void element, so it does not need a closing tag.
- Use meaningful `alt` text for images to improve accessibility.
- Use `href` with `<a>` to specify where a hyperlink goes.
- Use `src` with `<img>` to specify the image source.

---

## 🚀 Key Takeaways

- HTML provides structure and content, while attributes provide additional information about elements.
- Nesting allows HTML elements to be organized into a meaningful structure.
- Links and images make HTML pages more useful and interactive.
