## 💡 What I Learned

- Colors can be specified using named colors or hexadecimal color codes.
- `1px` is defined as `1/96` of an inch in CSS.
- `1pt` is defined as `1/72` of an inch. Microsoft Word commonly uses points for font sizes.
- `font-size` can be specified using units such as `px`, `pt`, `em`, and `rem`.
- `1em` is relative to the font size of the element's parent.
- `1rem` is relative to the font size of the root element, usually `<html>`.
- `font-weight` can use keywords such as `normal` and `bold`, relative values such as `lighter` and `bolder`, or numeric values such as `100`–`900`.
- `text-align` can be used to align text, such as `left`, `right`, `center`, `start`, and `end`.
- `margin`, `padding`, and `border` control different parts of the CSS box model.
- Margin creates space outside an element's border.
- Padding creates space between an element's content and its border.
- A `<div>` is a block-level container that can group and organize other elements.

---

## ⚠️ Things to Remember

- `color` controls the text color.
- `background-color` controls the background color.
- Both can use named colors, hexadecimal values, and other CSS color formats.
- Common font properties include `font-family`, `font-size`, and `font-weight`.
- `font-family` can specify a preferred font followed by generic fallback fonts.
- [Google Fonts](https://fonts.google.com/) provides custom fonts that can be used in webpages.
- Padding creates space **inside** the border.
- Margin creates space **outside** the border.
- Border surrounds the element's content and padding.
- Think of the box model as:

  Content → Padding → Border → Margin

- `<div>` elements are containers. They don't have a visual appearance by default, but CSS can give them size, color, borders, spacing, and other styling.

---

## 🚀 Key Takeaways

- The CSS box model explains how content, padding, borders, and margins determine the space an element occupies.
- CSS properties control not only how elements look, but also how they are sized, positioned, and spaced.
- Understanding relative units like `em` and `rem` will make CSS sizing more flexible.
