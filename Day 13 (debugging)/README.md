# Day X – Beginner – Debugging: How to Find and Fix Errors in Your Code

## 📚 Today's Concepts
- Debugging
- Bugs = problems that prevent code from doing what we want
- Describe the problem and reproduce the bug before trying to fix it
- Using print statements to see what is happening inside the program
- Using the debugger to step through code and inspect variables
- Understanding how `if`, `elif`, and `else` are connected
- Understanding indentation and which statement an `else` belongs to

---

## 🛠️ What I Built
- Fixed an index out of range error
- Debugged a FizzBuzz program
- Fixed multiple `if` statements causing multiple outputs

---

## 💡 What I Learned
- Print statements can be used to debug code by showing the current value of variables.
- The debugger lets you step through code and see what is happening at each step.
- `if`, `elif`, and `else` are connected, while separate `if` statements are evaluated independently.
- Indentation determines which statement an `else` belongs to.
- A `for` loop can have its own `else` statement.
- Debugging isn't just looking for syntax errors; the code can run successfully while still producing the wrong result.
- Reproducing the bug makes it easier to understand what is actually going wrong.

---

## ⚠️ Things to Remember
- Don't immediately rewrite code when something doesn't work. First figure out what the code is actually doing.
- Use print statements to check the values of variables when debugging.
- Use the debugger to step through code line by line.
- Check indentation when `if`, `elif`, `else`, loops, and functions aren't behaving as expected.
- Separate `if` statements are not the same as an `if / elif / else` chain.
- A program can run without errors and still have a logic bug.
- Fix bugs as you encounter them instead of letting them pile up.

---

## 🚀 Key Takeaways
- The biggest lesson today was learning to trace what the code is actually doing instead of assuming what it should do.
- I learned that debugging is about identifying the exact point where the program's behavior differs from what I expected.
- Understanding control flow and indentation will make it much easier to find logic bugs in future projects.
