## 💡 What I Learned

* Functions are reusable pieces of code designed to perform a specific task.
* A function is **defined** with `def` and **called** by using its name followed by `()`.
* Indentation is important in Python because it determines which code belongs to a function, loop, or conditional statement.
* `for` loops are useful when I want to iterate through a collection or repeat something a known number of times.
* `while` loops are useful when I don't know how many times something needs to happen and instead want to continue until a condition becomes false.
* A `while` loop checks its condition repeatedly and stops when the condition is `False`.
* `while True` creates a loop that will continue indefinitely unless something inside the loop causes it to stop.
* `if / elif / else` allows the program to make decisions based on different conditions.
* Reeborg helped me understand how programs can react to their environment instead of following a fixed sequence of instructions.

---

## ⚠️ Things to Remember

* Python uses indentation to determine how code is organized.
* Use **consistent indentation**. The standard Python convention is **4 spaces per indentation level**.
* Don't mix tabs and spaces in the same code.
* `while` loops can accidentally become infinite loops if the condition never becomes `False`.
* `for` loops are generally used when iterating through something or when the number of iterations is known.
* `while` loops are useful when the number of iterations is unknown and depends on a condition.
* Always think about **what will eventually make my `while` condition false?**
